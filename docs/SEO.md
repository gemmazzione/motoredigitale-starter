# SEO Guidelines

## Core SEO Principles

Every public page must have:

- unique title
- unique meta description
- canonical URL
- Open Graph title
- Open Graph description
- Open Graph image

## Technical SEO

Ensure:

- semantic HTML
- correct heading hierarchy
- only one H1 per page
- descriptive alt text
- descriptive internal links
- sitemap.xml
- robots.txt
- clean URLs
- fast page loading
- mobile usability

## Local SEO

When relevant include:

- business name
- city / service area
- phone number
- address
- opening hours
- Google Business Profile link
- LocalBusiness structured data

## Projects / Realizzazioni

Use descriptive project titles.

Where appropriate include:

- type of project
- service performed
- city / area
- industry

## Images

Use:

- descriptive filenames
- meaningful alt text
- compressed formats
- responsive images

Avoid:

- IMG_1234.jpg
- keyword stuffing
- duplicate alt text

## Structured Data

Consider:

- LocalBusiness
- Organization
- Service
- Product
- FAQPage
- BreadcrumbList

Only add structured data when it accurately reflects visible page content.

- title
- description
- canonical
- OG metadata
- sitemap
