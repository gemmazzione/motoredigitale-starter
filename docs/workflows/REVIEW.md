# Review Workflow

Review the website as if it were ready to be delivered to a paying client.

Check:

## Design

- Does the website feel specific to this client?
- Does anything look generic or AI-generated?
- Is the hierarchy strong?
- Is spacing consistent?
- Are images used effectively?
- Are animations purposeful?

## Mobile

Test approximately:

- 375px
- 768px
- 1024px
- 1440px

Check:

- overflow
- navigation
- typography
- image cropping
- CTA visibility
- interaction usability

## Conversion

- Is the main CTA obvious?
- Can the user quickly understand what the company does?
- Are contact actions easy?
- Is there unnecessary friction?

## SEO

- unique titles
- descriptions
- canonical
- headings
- alt text
- sitemap
- robots
- structured data when relevant

## Performance

- image size
- unnecessary JavaScript
- unnecessary dependencies
- layout shifts
- console errors

## Final output

Provide:

1. critical issues
2. recommended improvements
3. optional improvements

Fix critical issues before declaring the project ready.
