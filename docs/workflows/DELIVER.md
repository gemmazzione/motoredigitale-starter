# Delivery Workflow

Before delivery:

1. Run:

npm run build

2. Confirm the build succeeds.

3. Verify production-ready files.

4. Check:

- domain configuration
- HTTPS
- www / non-www behaviour
- forms
- phone links
- WhatsApp links
- email links
- privacy links
- cookie system when required
- analytics when configured
- sitemap
- robots
- favicon
- 404 page

5. Remove:

- demo content
- placeholders
- unused images
- unused components
- console logs
- development-only code

6. Provide a final delivery report containing:

- pages created
- main features
- SEO setup
- deployment notes
- remaining client actions
