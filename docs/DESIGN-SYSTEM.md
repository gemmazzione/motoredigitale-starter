## Animations

- low
- medium
- high

Preferred motion:

- fade
- reveal

Animations must support the visual narrative.

## Mobile

Mobile is not a reduced desktop version.

Preserve:

- brand personality
- hierarchy
- visual impact
- primary CTA

Simplify interactions when necessary.

## Accessibility

Maintain:

- readable contrast
- readable font sizes
- visible focus states
- accessible buttons
- sufficient spacing
